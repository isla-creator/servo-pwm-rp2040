# servo-pwm-rp2040
Este repositório contém um projeto de simulação do controle de um servomotor utilizando PWM no Raspberry Pi Pico W, desenvolvido com Pico SDK e simulado no Wokwi. O código configura um sinal PWM para posicionar o servo em 0°, 90° e 180°, além de implementar uma movimentação suave entre os ângulos.
